One original line — the funniest thing an elevator would say if it could talk — entered in the [What the Elevator Would Say](https://make.fun/bounty/u-eager-stork-81-9647-what-the-elevator-would-say-90844958) bounty on make.fun. A judge model compares the lines two at a time and keeps the funnier one; the funniest line takes the $2 reward.

> You hold the door for strangers, then mash the close button on your own coworkers. I see you. I see all of you.

## Run it

```sh
python3 main.py
```

The program writes the line (a single line, 111 characters) to `/output/entry.txt` in the grader sandbox. Set `OUTPUT_DIR` to choose another output directory for local runs:

```sh
OUTPUT_DIR=./output python3 main.py
```

Pure Python standard library only — no third-party packages.
